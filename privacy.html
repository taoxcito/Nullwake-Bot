Política de Privacidad

Información sobre el tratamiento de datos
Última actualización: 11 de agosto de 2026

Esta Política de Privacidad explica cómo Nullwake-Bot (el "Bot") recopila, utiliza, almacena y protege determinada información cuando los usuarios interactúan con él dentro de Discord.

El Bot es un servicio de terceros desarrollado y operado por taoxcito.

1. Información que recopilamos

Nullwake-Bot puede almacenar determinados datos necesarios para proporcionar sus funcionalidades.

1.1 Identificadores de Discord

Podemos almacenar identificadores proporcionados por Discord, incluyendo:

  • ID de usuario.
  • ID de servidor.
  • ID de canal cuando sea necesario para determinadas funcionalidades.
  • Otros identificadores técnicos necesarios para asociar configuraciones o datos del Bot.

1.2 Datos de economía virtual

Cuando utilizas las funciones económicas del Bot, podemos almacenar información asociada a tu cuenta dentro del sistema, incluyendo:

  • Balance o cantidad de moneda virtual.
  • Recompensas.
  • Estadísticas relacionadas con la economía.
  • Historial necesario para mantener la integridad del sistema económico, cuando corresponda.
Los datos de economía virtual no representan dinero real ni constituyen información financiera real.

1.3 Información relacionada con moderación

Cuando un servidor utiliza funcionalidades de moderación del Bot, podemos almacenar información necesaria para proporcionar dichas funciones.

Esto puede incluir:

  • Identificadores de usuarios involucrados en acciones de moderación.
  • Identificadores de servidores.
  • Identificadores de canales.
  • Registros de acciones de moderación.
  • Información necesaria para aplicar configuraciones o sanciones.
  • Datos técnicos relacionados con eventos de moderación.

2. Para qué utilizamos la información

La información recopilada puede utilizarse para:

  • Proporcionar las funcionalidades del Bot.
  • Mantener balances y sistemas de economía virtual.
  • Guardar configuraciones de servidores.
  • Proporcionar herramientas de moderación.
  • Detectar y prevenir abusos.
  • Corregir errores.
  • Mantener la seguridad y estabilidad del servicio.
  • Investigar problemas técnicos.
  • Responder a solicitudes de soporte.
  • Cumplir obligaciones legales cuando corresponda.

3. Información que no recopilamos deliberadamente

Salvo que una funcionalidad específica del Bot lo requiera y se informe expresamente, Nullwake-Bot no pretende recopilar deliberadamente:

  • Contraseñas de Discord.
  • Tokens de Discord.
  • Información de tarjetas bancarias.
  • Datos financieros reales.
  • Documentos de identidad.
  • Información médica.
Nunca debes proporcionar contraseñas, tokens de Discord u otra información altamente sensible al Bot.

4. Mensajes y contenido

El Bot puede recibir información relacionada con mensajes cuando una funcionalidad o interacción lo requiera.

No almacenamos deliberadamente el contenido completo de las conversaciones privadas o de los mensajes de un servidor salvo que una funcionalidad específica lo requiera y dicha recopilación sea informada de manera correspondiente.

Si en el futuro se implementa una función que requiera almacenar contenido de mensajes, esta Política de Privacidad será actualizada para explicar qué contenido se almacena, por qué y durante cuánto tiempo.

5. Conservación de datos

Conservamos la información únicamente durante el tiempo razonablemente necesario para proporcionar las funcionalidades correspondientes, mantener la seguridad del servicio, resolver problemas o cumplir obligaciones legales.

Los datos relacionados con una cuenta o servidor pueden eliminarse cuando dejen de ser necesarios o cuando corresponda atender una solicitud válida de eliminación.

Algunos registros técnicos o de seguridad pueden conservarse durante un período adicional cuando sea necesario para prevenir abusos, resolver incidentes o cumplir obligaciones legales.

6. Solicitud de eliminación de datos

Puedes solicitar la eliminación de los datos asociados a tu cuenta de Discord o a un servidor cuando corresponda.

Para realizar una solicitud, contacta con nosotros:

Correo: taoxcito@proton.me

Discord: taoxcito

La solicitud debería incluir tu ID de Discord y, cuando corresponda, el ID del servidor relacionado con los datos.

Podremos solicitar información adicional para verificar que la solicitud corresponde al titular o administrador correspondiente.

7. Seguridad

Aplicamos medidas razonables para proteger la información almacenada frente a accesos no autorizados, pérdida, alteración o divulgación.

Sin embargo, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

8. Compartición de información

No vendemos ni alquilamos los datos recopilados por Nullwake-Bot.

Podemos compartir información limitada cuando sea necesario para:

  • Proporcionar el servicio.
  • Utilizar proveedores técnicos necesarios para operar el Bot.
  • Detectar o prevenir abusos.
  • Cumplir obligaciones legales.
  • Responder a solicitudes legales válidas.
  • Proteger los derechos, seguridad o integridad del Bot, sus usuarios o terceros.

9. Servicios de terceros

Nullwake-Bot funciona dentro de Discord y depende de servicios proporcionados por terceros.

Discord mantiene sus propias Condiciones de Servicio y Política de Privacidad, que son independientes de esta Política.

Ver la Política de Privacidad de Discord →

10. Menores de edad

El Bot no está diseñado para recopilar deliberadamente información personal de menores de edad.

El uso de Discord está sujeto a los requisitos de edad y condiciones establecidos por Discord.

11. Transferencias y almacenamiento

Los datos pueden ser almacenados o procesados mediante infraestructura ubicada en distintos países, dependiendo de los proveedores técnicos utilizados para operar el Bot.

Al utilizar el Bot, reconoces que la información puede ser procesada fuera de tu país de residencia, sujeto a las medidas y requisitos legales aplicables.

12. Derechos de privacidad

Dependiendo de tu país o región, puedes tener determinados derechos relacionados con tus datos personales, incluyendo:

  • Solicitar acceso a determinados datos.
  • Solicitar la corrección de información incorrecta.
  • Solicitar la eliminación de datos.
  • Solicitar determinadas restricciones sobre el procesamiento.
  • Oponerte a determinados usos cuando corresponda.
  • Solicitar información sobre cómo se utilizan tus datos.

Puedes ejercer estos derechos contactando con nosotros mediante los datos indicados en esta Política.

13. Cambios en esta Política

Podemos actualizar esta Política de Privacidad cuando sea necesario para reflejar cambios en el Bot, nuestras prácticas de datos, servicios utilizados o requisitos legales aplicables.

La versión vigente estará publicada en esta página y mostrará la fecha de su última actualización.

14. Contacto

Para preguntas, solicitudes de privacidad o solicitudes relacionadas con tus datos:

Responsable: taoxcito

Correo: taoxcito@proton.me

Discord: taoxcito
