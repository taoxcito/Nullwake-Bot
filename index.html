1. Descripción del servicio

Nullwake Bot es una aplicación desarrollada para Discord que puede proporcionar funcionalidades relacionadas con economía virtual, administración, moderación y otras herramientas para servidores y usuarios.

Las funcionalidades disponibles pueden cambiar, añadirse, modificarse o eliminarse en cualquier momento.

2. Requisitos de uso

Para utilizar el Bot debes:

  • Tener una cuenta de Discord válida.
  • Cumplir las Condiciones de Servicio y las Directrices de la Comunidad de Discord.
  • Utilizar el Bot únicamente para fines legales y legítimos.
  • Contar con los permisos necesarios para añadir o utilizar el Bot en un servidor.

El uso del Bot no sustituye las herramientas, sistemas de seguridad o mecanismos de moderación proporcionados por Discord.

3. Uso prohibido

No está permitido utilizar el Bot para:

  • Realizar actividades ilegales.
  • Intentar obtener acceso no autorizado al Bot, sus sistemas o datos.
  • Explotar errores, vulnerabilidades o fallos del Bot.
  • Interferir deliberadamente con el funcionamiento del Bot.
  • Utilizar automatizaciones abusivas destinadas a sobrecargar el servicio.
  • Intentar manipular, duplicar o alterar fraudulentamente los sistemas de economía virtual.
  • Utilizar el Bot para acosar, amenazar, defraudar o perjudicar a otros usuarios.
